# Love Blueprint — Social Visual Kit: Image Generation Prompts

**Purpose:** Fill photos for dating-app posts, Instagram/TikTok carousels, and
profile promotion. Each card must (a) look premium standalone, (b) carry real
astrological information, and (c) be instantly recognisable as Love Blueprint.

**Global style rules — paste these into EVERY prompt:**
> Flat vector illustration, no photorealism, no people's faces. Deep plum-black
> background (#140b15) with soft radial rose glow. Palette: crimson #8E0E2E,
> rose #FF4D6D, light rose #FF8FA3, gold #E8B96A, warm near-white text #F3E3E9.
> Elegant serif display type for headings (Playfair Display style), clean
> geometric sans for body. Thin gold hairline borders, 24px rounded corners.
> Delicate floating heart glyphs and star sparkles as accents, never cluttered.
> Midnight-rose luxury aesthetic, high contrast, WCAG-legible text.
> No lorem ipsum — all text must be real English, spelled correctly.

**Aspect ratios:**
- Story/Reel/TikTok: **1080×1920 (9:16)**
- Feed post: **1080×1350 (4:5)**
- Profile/square: **1080×1080 (1:1)**

**Logo:** Use `assets/logo.svg` (two arcs converging into a heart with a spark
at the conjunction point). Export PNG at 1024px with transparent background
before compositing. Do NOT let the image model redraw your logo — it will
distort it. Generate backgrounds/borders only, composite the logo separately
(Canva/Figma), OR prompt "leave the top-centre area empty for a logo".

## Production tips

1. **Generate illustrations, add text separately.** 90% of AI text is broken.
   Prompt the art, then set headings/bullets in Canva (Playfair Display +
   Inter to match the app).
2. **Consistency seed:** once a style works, reuse the same seed/style
   reference for the whole 8-card set so the carousel looks like one design.
3. **Export:** PNG at 2× for retina, sRGB.
4. **Test legibility at thumbnail:** every card must be readable at 300px wide
   in an Instagram grid.
5. **Fill order:** Card 1 → 8 tells the full story. Post as a carousel; each
   card also works standalone with the quantummerlin.com/loveblueprint tag.
